# Bundle OKF — Sprint 1

Este bundle reúne, en formato **OKF** (Open Knowledge Format: Markdown con frontmatter), cómo está realmente el Sprint 1 en este repositorio. Todo lo que aquí se afirma se puede comprobar en el código, los workflows, el README o el historial de git; lo que no se pudo comprobar aparece como **Por verificar**, y lo que solo puede escribir la persona responsable del proyecto aparece como **TODO(alumno)**.

Ejecución, tecnologías, variables de entorno y despliegue: en el [README](../README.md).
